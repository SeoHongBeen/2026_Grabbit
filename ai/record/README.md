# 실환경 녹음 안내

RPi에서 실행하는 스크립트입니다. **반드시 실제 기기 + 실제 마이크로** 녹음하세요.
노트북이나 폰으로 찍으면 의미가 없습니다 — 우리가 재려는 게 바로 그 마이크의
품질과 거리 특성이기 때문입니다.

## 왜 필요한가

현재 학습 데이터는 전부 Freesound에 올라온 깨끗한 녹음입니다. 마이크를 소리
가까이 대고, 조용한 환경에서, 좋은 장비로 딴 것들입니다.

실제 Grabbit은 방 한구석에 놓여 **5m 떨어진 소리를, 에어컨 소리에 묻힌 채,
저가 마이크로** 듣습니다. 이 차이 때문에 데이터셋 성능이 실환경에서
10~20%p 떨어지는 게 정상입니다.

지금 우리 평가 수치(사이렌 recall 0.875 등)는 전부 데이터셋 기준이라,
실환경에서 몇 %가 나올지는 **측정하기 전까지 알 수 없습니다.**

## 0. 마이크 점검 (건너뛰지 마세요)

```bash
cd 2026_Grabbit/ai/record
python3 check_mic.py
```

장치를 못 찾으면 목록을 보고 지정합니다:

```bash
arecord -l
python3 check_mic.py plughw:1,0
```

`[정상]`이 나와야 다음으로 넘어갑니다. 게인이 잘못돼 있으면 2시간을 녹음해도
전부 무음이라 통째로 버려야 합니다. `alsamixer`에서 Capture 볼륨을 조정하세요
(F4로 Capture 탭, M으로 음소거 해제).

## 1. 일상 소음 — 오알림 측정용

**목표**: 위험음이 하나도 없을 때 몇 번 헛울리는지

```bash
./record_ambient.sh plughw:1,0 2      # 2시간
```

- 기기를 **실제 설치할 위치**에 두고 그냥 방치, 평소처럼 생활하면 됩니다
- 최소 2시간, 많을수록 좋습니다
- 아침 1시간 + 저녁 1시간처럼 **시간대를 나누는 게** 한 번에 2시간보다 낫습니다
- 다양한 상황이 섞이면 좋습니다: 요리, 설거지, TV, 대화, 청소기, 문 여닫기
- 10분 단위로 파일이 나뉘므로 도중에 멈춰도 그때까지는 남습니다

**주의**: 이 시간엔 사이렌·유리 깨짐·노크가 나면 안 됩니다.
창밖에서 구급차가 지나갔다면 그 시각을 메모해 주세요.

## 2. 위험음 — 감지율 측정용

**목표**: 실제로 소리가 났을 때 몇 %나 잡는지

```bash
python3 record_events.py plughw:1,0
```

메뉴에서 클래스를 고르면 1m → 3m → 5m 순서로 5회씩 안내합니다.

| 클래스 | 방법 |
|---|---|
| knock | **실제로 문을 두드리세요.** 재생보다 정확합니다 |
| siren | 스피커로 재생 |
| glass | 스피커로 재생 |
| fire | 스피커로 재생 (저음이 잘 안 나와 결과가 실제보다 나쁠 수 있음) |

**거리를 나누는 게 핵심입니다.** 가까이서만 녹음하면 "다른 방 소리를 잡는가"를
알 수 없는데, 실제 사용에선 그게 대부분입니다.

**볼륨은 현실적으로.** 사이렌을 스피커 최대로 틀면 실제보다 쉬운 조건이 됩니다.
그 위치에서 실제로 들릴 법한 크기로 맞추세요.

## 3. PC로 옮기기

```
2026_Grabbit/ai/dataset/realworld/
  ambient/    ← 1번 결과 (긴 파일들)
  events/     ← 2번 결과 (짧은 파일들)
```

이 구조 그대로 옮기면 분석 스크립트가 바로 읽습니다.
파일명은 스크립트가 자동으로 규칙에 맞게 짓습니다 — **직접 바꾸지 마세요**
(`siren_3m_01.wav` 형식에서 클래스와 거리를 읽어옵니다).

## 예상 작업량

- **일상 소음**: 거의 안 듭니다 (걸어두고 생활)
- **위험음**: 1~2시간 (거리 옮겨가며 반복)

## 문제 해결

| 증상 | 해결 |
|---|---|
| `arecord: command not found` | `sudo apt install alsa-utils` |
| `bad interpreter` | `bash record_ambient.sh` 로 실행하거나 `dos2unix record_ambient.sh` |
| `Permission denied` | `chmod +x record_ambient.sh` |
| 장치를 못 찾음 | `arecord -l` 로 카드/장치 번호 확인 후 `plughw:카드,장치` 형식으로 지정 |
| 녹음이 무음 | `alsamixer` → F4 → Capture 볼륨 올리고 M으로 음소거 해제 |
